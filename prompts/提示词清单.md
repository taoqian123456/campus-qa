# AI 提示词清单（全周期，按顺序使用）

> 使用方法：打开 VSCode 的 Roo Code 面板，把提示词整段复制粘贴，按回车。
> 每条提示词都假设项目骨架已存在（backend 文件夹已就绪）。
> **铁律**：一次只做一条；AI 写完后先测试验收，再进入下一条；报错全文复制贴回 AI 让它修复。

```
继续开发我的毕业设计项目（后端在 backend/ 目录，已有 main.py、config.py、database.py、models.py，表结构已建好）。
请实现用户认证模块，新建 auth/ 目录，包含以下文件：
1. auth/schemas.py：注册请求模型（username, password，密码至少6位）、登录请求模型、Token 响应模型
2. auth/security.py：密码哈希（用 passlib 的 bcrypt；如果报 bcrypt 兼容错误就固定 pip install bcrypt==4.0.1）、JWT 生成与解析（python-jose，HS256，有效期7天，secret 用 config.py 里新增的 SECRET_KEY 配置项）
3. auth/routes.py：POST /api/auth/register（用户名重复返回400）、POST /api/auth/login（校验成功返回 {"access_token": "...", "token_type": "bearer"}）
4. auth/deps.py：get_current_user 依赖，从 Authorization: Bearer 头解析用户，查不到用户返回401
5. 在 config.py 里加 SECRET_KEY = os.getenv("SECRET_KEY", "dev-secret-change-me")，并在 .env 里加一行 SECRET_KEY=随便写一串字符
6. 在 main.py 里注册 auth 路由（app.include_router）
写完后告诉我：怎么在 http://127.0.0.1:8000/docs 里测试注册和登录，成功响应长什么样。
```

**验收**：/docs 里 register 能创建用户；login 能返回 token；拿着 token 调一个受保护接口（可以先写 GET /api/auth/me 返回当前用户信息）能成功、不带 token 返回 401。

3. 上传接口先不解析文本（解析留到 P3 建索引时做），只保存文件
4. 在 main.py 注册 admin 路由
写完后告诉我：怎么在 /docs 上传一个 PDF 测试，上传成功后怎么确认文件保存成功。

**验收**：/docs 上传 PDF 成功；列表能看到；控制台无报错。

## P3 向量索引（对应计划 D9，约 2 小时）

```
继续。请实现向量索引模块：
1. 嵌入模型：尝试用 langchain-openai 的 OpenAIEmbeddings 对接 DeepSeek 兼容接口（base_url 用 config.py 的 DEEPSEEK_BASE_URL，model='text-embedding-ada-002' 或 'embedding-v2'，api_key 用 DEEPSEEK_API_KEY）。
   重要：如果 DeepSeek 没有可用的嵌入模型接口（调用报错或文档说明不支持），就不要用 DeepSeek 嵌入，改用国内可用的免费/便宜嵌入 API（如硅基流动 SiliconFlow 的 BAAI/bge-m3，或智谱 embedding-2），把 base_url 和 model 做成 config.py 里的配置项 EMBEDDING_BASE_URL / EMBEDDING_MODEL，并告诉我申请哪个平台、怎么拿 key。
2. qa/vector_store.py：
   - 类 VectorStore：__init__ 时加载已有索引（faiss_index/index.faiss + 元数据 faiss_index/index.pkl），不存在则建空索引
   - 方法 add_documents(chunks)：对每个块生成向量加入索引，元数据保存块文本和来源文件名
   - 方法 search(query, top_k)：返回 [{"text": ..., "source": ..., "score": ...}]
   - 方法 save()：持久化到 faiss_index/ 目录
   - 方法 rebuild()：扫描 UPLOAD_DIR 下所有文档，重新解析、分块、建索引（删除旧索引重建）
3. 建一个可单独运行的脚本 rebuild_index.py：调用 extract_text → chunk_text → 嵌入 → 建索引 → save，运行完打印"共索引 N 个块"
4. config.py 增加 EMBEDDING 相关配置
写完后告诉我：怎么运行 rebuild_index.py，成功后在 faiss_index/ 目录下应该看到什么文件。
```

**验收**：往 uploads/ 放 1 篇你的政策 PDF，运行 `python rebuild_index.py`，输出"共索引 N 个块"，faiss_index/ 出现 index.faiss 和 index.pkl。

## P4 RAG 问答核心（对应计划 D10，约 2-3 小时）★ 最重要

```
继续。请实现 RAG 问答模块 qa/qa_handler.py：
1. 函数 answer_question(question, history=None)：
   - 用 VectorStore.search(question, TOP_K) 检索 top-5 块（TOP_K 从 config.py 读）
   - 组装 System Prompt（固定指令）：
     "你是一个高校学生事务政策问答助手。请仅根据下面【参考资料】中的内容回答用户问题。参考资料中没有的内容，必须明确回答'资料库中未找到相关信息'，严禁编造。回答使用中文，简洁准确，可以分点列出。\n\n【参考资料】\n{context}"
   - 调用 DeepSeek chat 接口（openai 库，base_url=DEEPSEEK_BASE_URL，model=DEEPSEEK_CHAT_MODEL），temperature=0.3
   - 返回 {"answer": "...", "sources": ["文件名1", "文件名2"]}（sources 来自检索结果去重）
   - history 参数先预留（多轮上下文后面再加），可以传最近几轮对话文本拼进 User Prompt
2. 新建 chat/ 目录实现会话接口：
   - POST /api/chat/sessions：新建会话，标题取问题前20字
   - GET /api/chat/sessions：列出当前用户的会话（按时间倒序）
   - DELETE /api/chat/sessions/{id}：删除会话（同时删消息）
   - POST /api/chat/sessions/{id}/messages：body 传 {question}，调用 answer_question，把问题和答案写入 messages 表，返回 {answer, sources}
   - GET /api/chat/sessions/{id}/messages：获取会话历史
3. 在 main.py 注册 chat 路由
写完后告诉我：在 /docs 里怎么完整测试：建会话 → 发问题 → 看回答和来源。
```

**验收**：问"转专业需要什么条件"，回答内容来自你的政策文档且带来源文件名；问一个文档里没有的问题，回答"资料库中未找到相关信息"而不是编造。

```
请写评测脚本 evaluate.py（放 backend/ 下）：

```
请用 3 句话解释你刚写的这个模块的作用，并用最通俗的语言说明我该怎么向别人介绍它。
